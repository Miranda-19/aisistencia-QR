Instrucciones de uso
  1. Presione el botón Activar cámara.
  2. Permita el acceso a la cámara cuando el navegador lo solicite.
  3. Coloque el código QR frente a la cámara.
  4. El sistema registrará la asistencia automáticamente.
  5. El lector quedará listo para el siguiente participante.
